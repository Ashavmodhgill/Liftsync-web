# 📖 Overview

LiftSync is an AI-powered real-time fitness coaching platform designed to help users improve workout performance through intelligent motion analysis and exercise tracking.

Using computer vision and pose estimation technologies, LiftSync analyzes body movements through a webcam, identifies exercise patterns, counts repetitions automatically, and provides live feedback on exercise form and technique.

The project aims to bridge the gap between traditional fitness training and artificial intelligence by providing users with a virtual personal trainer experience accessible from anywhere.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Ashavmodhgill/LiftSync.git
```

Move into the project directory:

```bash
cd LiftSync
```

---

## Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Application

### Python

```bash
python main.py
```

### Streamlit

```bash
streamlit run main.py
```
